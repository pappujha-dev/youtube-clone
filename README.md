# YouTube Clone

A front-end YouTube-inspired website created using HTML and CSS.

## Features
- YouTube-inspired homepage layout
- Navigation sidebar
- Video thumbnail sections
- Shorts section
- Channel profile images
- Responsive-style layout

## Technologies Used
- HTML5
- CSS3

## Project Structure
- images/index.htm - Main HTML page
- images/style.css - Stylesheet
- images/logo - Local logo and profile image assets
- images/thumb - Video thumbnail assets
- images/shorts - Shorts thumbnail assets

## How to Run
1. Clone or download this repository.
2. Open images/index.htm in your browser.
